# TRIAURAL – Technical Drawings (TRIATLAS-MARS)

Blueprints of the TRIAURAL monolithic resonators. All drawings show the **plain finish** (no spiral grooves, no logo). All dimensions are in millimetres.

## `tetramid/` – MARS–TRIAURAL–TETRAMID specimen set

- **`TRIATLAS-MARS_TETRAMID_all-sections_22-44-66_EN.png`**: overview of all 12 specimens on one sheet (4 cross-sections × 3 sizes).
- **`TRIATLAS-MARS_TETRAMID_<size>_<section>_EN.png`**: full drawing of each specimen, with front, side, top, bottom, axonometric, section and node-detail views.
- **`TRIATLAS-MARS_TETRAMID_<section>_22-44-66_EN.png`**: size comparison for one cross-section.
- **`TRIATLAS-MARS_TETRAMID_drawings_EN.pdf`**: all sheets in one PDF.
